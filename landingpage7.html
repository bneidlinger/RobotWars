EXECUTION DISCIPLINE New

Every submitted routine now runs under enforced limits:

  • → Per-Tick Clock: Hard 100ms ceiling, now actually enforced
  • → Memory Ceiling: Per-cell allocation cap
  • → Graceful Ejection: A cell that exceeds its ceiling is retired without disturbing the match
  • → Recoverable Timeouts: A stalled routine is cut off but retried next tick
  • → Isolated State: One robot cannot observe or corrupt another's memory
  • → Clean Boundary: Only copied numeric data crosses the wall

DETONATION DECAY REPAIR Critical

The "permanent sun" anomaly is resolved. Detonation effects were being aged against the wrong clock unit — roughly a thousand times slower than intended — so they never expired:

  • → Symptom: Blast effects accumulated at full intensity until they saturated into fixed white masses
  • → Persistence: The artifacts survived between matches and accumulated across sessions
  • → Cause: Clock unit mismatch between the combat loop and the effects system
  • → Repair: Corrected units, frame-rate independent decay, and a purge between engagements
  • → Result: Detonations now bloom and clear in roughly a second, as designed

ILLUMINATION CALIBRATION New

Blast illumination is now calibrated against surface brightness rather than fixed:

  • → Surface-Linked Intensity: Each surface carries its own illumination scaling
  • → No Saturation: Overlapping detonations bloom without washing to white
  • → Concurrent Cap: Simultaneous light sources are bounded
  • → Automatic Rebalance: Switching surfaces re-derives illumination automatically
  • → Day / Dusk / Night: All ambient profiles verified against both surfaces
